# ColourShift — HEX, RGB & HSL Converter

Instantly convert colours between HEX, RGB and HSL with a live preview, colour picker, sliders and copy-ready CSS values.

## Use
Open `colourshift.html` in any modern browser — or try it live on Asif SaaS Studio: https://headless-pmvjliowzro-ftonlineclass-140d.wix-site-host.com/app.html?slug=colourshift

Everything runs locally in the browser: no uploads, no tracking, no accounts. See `colourshift-test-report.md` for the v1.0 test report.
